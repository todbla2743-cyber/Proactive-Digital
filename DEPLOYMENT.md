# Proactive Digital deployment

Netlify builds the `main` branch and publishes the `dist` directory generated by `scripts/build-public.sh`. The script lists every public file explicitly. When adding a new page or asset, add it to that list and verify its internal links before merging.

The root of this repository contains older archives and a lab page for development; they are not part of the public site. The `dist` directory is generated during the build and must not be committed.

The production release includes the MRA case study, desktop portfolio previews, `/pay` and `/payment` routes, and the Stripe payment link on `pay.html`.
